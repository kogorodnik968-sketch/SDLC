## Описание проекта

Приложение на языке Java с графическим интерфейсом (Swing), построенное
по архитектурному паттерну MVC с активной моделью.

Пользователь вводит зарплату, количество рабочих часов по договору
и реально отработанные часы. Программа рассчитывает:

- стоимость одного клика мышью;
- стоимость одной строки кода;
- стоимость одного рабочего вздоха;
- стоимость глубокого вздоха;
- стоимость одного бага;
- стоимость кофе-брейка;
- итоговый вердикт о «стоимости сотрудника».

---

## Функциональность

- Ввод исходных данных через отдельное диалоговое окно
- Двухуровневая валидация данных (мгновенная + финальная)
- Сохранение последних корректно введённых значений
- Автоматический пересчёт показателей при изменении данных
- Цветовая индикация результатов в зависимости от их значений

## Архитектура

Проект построен по паттерну **MVC с активной моделью**:

- **Model** (`SalaryModel`, `Constants`) — хранение данных и расчёты;
- **View** (`MainView`, `InputDialog`) — отображение и ввод;
- **Controller** (`MainController`) — обработка действий пользователя.

Активная модель реализована через `PropertyChangeSupport`: при изменении
данных модель сама уведомляет представление, и интерфейс обновляется
автоматически.
